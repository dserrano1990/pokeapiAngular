# PokeApi

Aplicación Angular que consume la API pública de Pokémon.

## Tecnologías
- Angular
- TypeScript
- PokeAPI

## Funcionalidades
- Listado de Pokémon
- Detalle de Pokémon
- Consumo de API REST

## Instalación
npm install
ng serve
